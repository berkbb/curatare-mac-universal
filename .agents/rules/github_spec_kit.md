## 1. Lifecycle Protocol

1. **Constitution:** Enforce `.agents/AGENTS.md` invariants (Dated-Trash-Only, Protection Rules, Running-Process Guard, Sandbox Isolation, Trilingual Parity).
2. **Specify & Plan:** Map user requirements (`Mole` + `library_clean.md` + uninstaller + GitHub Mole updater) to concrete `CuratareCore` and `Curatare` modules.
3. **Implement & Converge:** Verify with `swift test`, `./Scripts/build_app.sh`, and `./Scripts/verify_bundle.sh`.
